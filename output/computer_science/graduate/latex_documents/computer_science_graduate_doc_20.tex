\begin{enumerate}[label=\arabic*.]
\item Which of the following statements about a remote procedure call is true?
\begin{enumerate}[label=(\alph*)]
    \item It is used to call procedures with addresses that are farther than $2^16$ bytes away.
    \item It cannot return a value.
    \item It cannot pass parameters by reference.

\begin{enumerate}[label=(\alph*)]
    \item The Caesar Cipher, a substitution cipher
    \item DES (Data Encryption Standard), a symmetric-key algorithm
    \item Enigma, a transposition cipher
    \item One-time pad
\end{enumerate}

\begin{enumerate}[label=(\alph*)]

    \item accepted by some Turing machine, but by no pushdown automaton

\end{enumerate}
