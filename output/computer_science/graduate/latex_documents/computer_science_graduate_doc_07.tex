\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item The \_\_\_\_\_\_\_\_\_\_\_\_\_\_ is categorized as an unknown segment of the Deep Web which has been purposely kept hidden \& is inaccessible using standard web browsers.

\item Which of the following is not a transport layer vulnerability?
\begin{enumerate}[label=(\alph*)]
    \item Mishandling of undefined, poorly defined variables
    \item The Vulnerability that allows "fingerprinting" \& other enumeration of host information
    \item Overloading of transport-layer mechanisms
    \item Unauthorized network access
\end{enumerate}
\item Which of the following statements about a remote procedure call is true?
\begin{enumerate}[label=(\alph*)]
    \item It is used to call procedures with addresses that are farther than $2^16$ bytes away.
    \item It cannot return a value.
    \item It cannot pass parameters by reference.
    \item It cannot call procedures implemented in a different language.
\end{enumerate}
\item If p(x) is the minimal-degree interpolating polynomial for the real-valued function f(x) at the n + 1 distinct real numbers x 0, .... xn what is the maximum possible degree of p(x)?
\begin{enumerate}[label=(\alph*)]
    \item n
    \item n + 1
    \item n + 2
    \item 2 n
\end{enumerate}
\item Which of the following instruction-set features is NOT generally considered an obstacle to aggressive pipelining of an integer unit?
\begin{enumerate}[label=(\alph*)]
    \item Condition codes set by every instruction
    \item Variable-length encoding of instructions
    \item Instructions requiring widely varying numbers of cycles to execute
    \item Several different classes (sets) of registers
\end{enumerate}
\end{enumerate}
