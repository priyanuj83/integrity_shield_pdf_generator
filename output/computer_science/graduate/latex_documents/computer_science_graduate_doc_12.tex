\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following is true of interrupts?
\begin{enumerate}[label=(\alph*)]
    \item They are generated when memory cycles are "stolen".
    \item They are used in place of data channels.
    \item They can indicate completion of an I/O operation.
    \item They cannot be generated by arithmetic operations.
\end{enumerate}
\item How is IP address spoofing detected?
\begin{enumerate}[label=(\alph*)]
    \item Installing and configuring a IDS that can read the IP header
    \item Comparing the TTL values of the actual and spoofed addresses
    \item Implementing a firewall to the network
    \item Identify all TCP sessions that are initiated but does not complete successfully
\end{enumerate}
\item You are given a message (m) and its OTP encryption (c). Can you compute the OTP key from m and c ?
\begin{enumerate}[label=(\alph*)]
    \item No, I cannot compute the key.
    \item Yes, the key is k = m xor c.
    \item I can only compute half the bits of the key.
    \item Yes, the key is k = m xor m.
\end{enumerate}
\item A hash function guarantees the integrity of a message. It guarantees that the message has not be
\begin{enumerate}[label=(\alph*)]
    \item Replaced
    \item Overview
    \item Changed
    \item Violated
\end{enumerate}
\item What are the port states determined by Nmap?
\begin{enumerate}[label=(\alph*)]
    \item Active, inactive, standby
    \item Open, half-open, closed
    \item Open, filtered, unfiltered
    \item Active, closed, unused
\end{enumerate}
\end{enumerate}
