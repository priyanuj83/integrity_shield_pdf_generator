\item Of the following problems concerning a given undirected graph G, which is currently known to be solvable in polynomial time?

    \item Finding a shortest cycle in G
    \item Finding ALL spanning trees of G
    \item Finding a largest clique in G

\item In Python 3, which of the following function convert a string to an int in python?
\begin{enumerate}[label=(\alph*)]
    \item int(x [,base])
    \item long(x [,base] )

    \item str(x)
\end{enumerate}
\item What is the output of the statement "a" + "ab" in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item Error
    \item aab
    \item ab
    \item a ab
\end{enumerate}
\item What is the output of "abc"[::-1] in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item Error
    \item abc
    \item cba
    \item c
\end{enumerate}
\item In Python 3, b = [11,13,15,17,19,21]; print(b[::2]) outputs what?
\begin{enumerate}[label=(\alph*)]
    \item [19,21]
    \item [11,15]
    \item [11,15,19]
    \item [13,17,21]
\end{enumerate}
\end{enumerate}
