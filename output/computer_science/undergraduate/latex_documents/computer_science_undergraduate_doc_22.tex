\item Local caching of files is common in distributed file systems, but it has the disadvantage that
\begin{enumerate}[label=(\alph*)]
    \item Temporary inconsistencies among views of a file by different machines can result
    \item The file system is likely to be corrupted when a computer crashes
    \item A much higher amount of network traffic results

\begin{enumerate}[label=(\alph*)]

    \item Recursive procedures
    \item Arbitrary goto's
    \item Two-dimensional arrays
    \item Integer-valued functions
\end{enumerate}
\item A$_{3}$-way, set-associative cache is
\begin{enumerate}[label=(\alph*)]
