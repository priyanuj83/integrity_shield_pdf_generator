\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following statements about a remote procedure call is true?
\begin{enumerate}[label=(\alph*)]
    \item It is used to call procedures with addresses that are farther than $2^16$ bytes away.
    \item It cannot return a value.
    \item It cannot pass parameters by reference.
    \item It cannot call procedures implemented in a different language.
\end{enumerate}
\item Which is a valid expression in Python 3.5?
\begin{enumerate}[label=(\alph*)]
    \item sort('ab')
    \item sorted('ab')
    \item "ab".sort()
    \item 1/0
\end{enumerate}
\item Let l = [1,2,2,3,4]. In Python 3, what is a possible output of set(l)?
\begin{enumerate}[label=(\alph*)]
    \item \{1\}
    \item \{1,2,2,3,4\}
    \item \{1,2,3,4\}
    \item \{4,3,2,2,1\}
\end{enumerate}
\item Which of the following is not a sentence that is generated by the grammar A -\textgreater{} BC, B -\textgreater{} x|Bx, C -\textgreater{} B|D, D -\textgreater{} y|Ey, E -\textgreater{} z?
\begin{enumerate}[label=(\alph*)]
    \item xyz
    \item xy
    \item xxzy
    \item xxxxy
\end{enumerate}
\item Which of the following statements is FALSE about memory reclamation based on reference counting?
\begin{enumerate}[label=(\alph*)]
    \item Reference counting is well suited for reclaiming cyclic structures.
    \item Reference counting incurs additional space overhead for each memory cell.
    \item Reference counting is an alternative to mark-and-sweep garbage collection.
    \item Reference counting need not keep track of which cells point to other cells.
\end{enumerate}
\end{enumerate}
