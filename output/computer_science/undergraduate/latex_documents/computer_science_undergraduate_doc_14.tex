\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following sorting algorithms has average-case and worst-case running times of O(n log n)?
\begin{enumerate}[label=(\alph*)]
    \item Bubble sort
    \item Insertion sort
    \item Merge sort
    \item Quicksort
\end{enumerate}
\item Of the following, which gives the best upper bound for the value of f(N) where f is a solution to the recurrence f(2 N + 1) = f(2 N) = f(N) + log N for N \textgreater{}= 1, with f(1) = 0?
\begin{enumerate}[label=(\alph*)]
    \item O(log N)
    \item O(N log N)
    \item O(log N) + 0(1)
    \item O((log $N)^2$)
\end{enumerate}
\item Let x = 8. What is x\textgreater{}\textgreater{}1 in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item 3
    \item 4
    \item 2
    \item 8
\end{enumerate}
\item In the Internet Protocol (IP) suite of protocols, which of the following best describes the purpose of the Address Resolution Protocol?
\begin{enumerate}[label=(\alph*)]
    \item To translate Web addresses to host names
    \item To determine the IP address of a given host name
    \item To determine the hardware address of a given host name
    \item To determine the hardware address of a given IP address
\end{enumerate}
\item Of the following page-replacement policies, which is guaranteed to incur the minimum number of page faults?
\begin{enumerate}[label=(\alph*)]
    \item Replace the page whose next reference will be the longest time in the future.
    \item Replace the page whose next reference will be the shortest time in the future.
    \item Replace the page whose most recent reference was the shortest time in the past.
    \item Replace the page whose most recent reference was the longest time in the past.
\end{enumerate}
\end{enumerate}
