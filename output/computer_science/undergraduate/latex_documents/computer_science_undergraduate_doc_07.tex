\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item In Python 3, b = [11,13,15,17,19,21]; print(b[::2]) outputs what?
\begin{enumerate}[label=(\alph*)]
    \item [19,21]
    \item [11,15]
    \item [11,15,19]
    \item [13,17,21]
\end{enumerate}
\item Which of the following sorting algorithms has average-case and worst-case running times of O(n log n)?
\begin{enumerate}[label=(\alph*)]
    \item Bubble sort
    \item Insertion sort
    \item Merge sort
    \item Quicksort
\end{enumerate}
\item Which of the following decimal numbers has an exact representation in binary notation?
\begin{enumerate}[label=(\alph*)]
    \item 0.1
    \item 0.2
    \item 0.3
    \item 0.5
\end{enumerate}
\item Which of the following is the name of the data structure in a compiler that is responsible for managing information about variables and their attributes?
\begin{enumerate}[label=(\alph*)]
    \item Abstract Syntax Tree (AST)
    \item Attribute Grammar
    \item Symbol Table
    \item Semantic Stack
\end{enumerate}
\item Which of the following is NOT a property of bitmap graphics?
\begin{enumerate}[label=(\alph*)]
    \item Fast hardware exists to move blocks of pixels efficiently.
    \item Realistic lighting and shading can be done.
    \item All line segments can be displayed as straight.
    \item Polygons can be filled with solid colors and textures.
\end{enumerate}
\end{enumerate}
