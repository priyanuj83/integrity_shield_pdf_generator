\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following statements is FALSE about memory reclamation based on reference counting?
\begin{enumerate}[label=(\alph*)]
    \item Reference counting is well suited for reclaiming cyclic structures.
    \item Reference counting incurs additional space overhead for each memory cell.
    \item Reference counting is an alternative to mark-and-sweep garbage collection.
    \item Reference counting need not keep track of which cells point to other cells.
\end{enumerate}
\item Of the following, which gives the best upper bound for the value of f(N) where f is a solution to the recurrence f(2 N + 1) = f(2 N) = f(N) + log N for N \textgreater{}= 1, with f(1) = 0?
\begin{enumerate}[label=(\alph*)]
    \item O(log N)
    \item O(N log N)
    \item O(log N) + 0(1)
    \item O((log $N)^2$)
\end{enumerate}
\item In Python 3, which of the following function sets the integer starting value used in generating random numbers?
\begin{enumerate}[label=(\alph*)]
    \item choice(seq)
    \item randrange ([start,] stop [,step])
    \item random()
    \item seed([x])
\end{enumerate}
\item Which of the following is not a sentence that is generated by the grammar A -\textgreater{} BC, B -\textgreater{} x|Bx, C -\textgreater{} B|D, D -\textgreater{} y|Ey, E -\textgreater{} z?
\begin{enumerate}[label=(\alph*)]
    \item xyz
    \item xy
    \item xxzy
    \item xxxxy
\end{enumerate}
\item Let x = 8. What is x\textgreater{}\textgreater{}1 in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item 3
    \item 4
    \item 2
    \item 8
\end{enumerate}
\end{enumerate}
