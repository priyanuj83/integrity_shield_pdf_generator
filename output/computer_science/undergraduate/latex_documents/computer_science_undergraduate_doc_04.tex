\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item A starvation-free job-scheduling policy guarantees that no job waits indefinitely for service. Which of the following job-scheduling policies is starvation-free?
\begin{enumerate}[label=(\alph*)]
    \item Round-robin
    \item Priority queuing
    \item Shortest job first
    \item Youngest job first
\end{enumerate}
\item Any set of Boolean operators that is sufficient to represent all Boolean expressions is said to be complete. Which of the following is NOT complete?
\begin{enumerate}[label=(\alph*)]
    \item \{AND, NOT\}
    \item \{NOT, OR\}
    \item \{AND, OR\}
    \item \{NAND\}
\end{enumerate}
\item In Python 3, what is the output of print tuple[0] if tuple = ( 'abcd', 786 , 2.23, 'john', 70.2 )?
\begin{enumerate}[label=(\alph*)]
    \item ( 'abcd', 786 , 2.23, 'john', 70.2 )
    \item abcd
    \item Error
    \item None of the above.
\end{enumerate}
\item Local caching of files is common in distributed file systems, but it has the disadvantage that
\begin{enumerate}[label=(\alph*)]
    \item Temporary inconsistencies among views of a file by different machines can result
    \item The file system is likely to be corrupted when a computer crashes
    \item A much higher amount of network traffic results
    \item Caching makes file migration impossible
\end{enumerate}
\item Which of the following is correct about Python?
\begin{enumerate}[label=(\alph*)]
    \item It supports automatic garbage collection.
    \item It can be easily integrated with C, C++, COM, ActiveX, CORBA, and Java.
    \item Both of the above.
    \item None of the above.
\end{enumerate}
\end{enumerate}
