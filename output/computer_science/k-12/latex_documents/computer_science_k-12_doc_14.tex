\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item What is the output of 4*1**4 in python?
\begin{enumerate}[label=(\alph*)]
    \item 4
    \item 1
    \item 256
    \item 16
\end{enumerate}
\item Which of the following has the greatest potential for compromising a user's personal privacy?
\begin{enumerate}[label=(\alph*)]
    \item A group of cookies stored by the user's Web browser
    \item The Internet Protocol (IP) address of the user's computer
    \item The user's e-mail address
    \item The user's public key used for encryption
\end{enumerate}
\item In Python 3, let r = lambda q: q * 2. What is r(3)?
\begin{enumerate}[label=(\alph*)]
    \item 2
    \item 6
    \item 3
    \item 1
\end{enumerate}
\item Which of the following is correct about Python?
\begin{enumerate}[label=(\alph*)]
    \item It supports automatic garbage collection.
    \item It can be easily integrated with C, C++, COM, ActiveX, CORBA, and Java.
    \item Both of the above.
    \item None of the above.
\end{enumerate}
\item A large Java program was tested extensively, and no errors were found. What can be concluded?
\begin{enumerate}[label=(\alph*)]
    \item All of the preconditions in the program are correct.
    \item All of the postconditions in the program are correct.
    \item The program may have bugs.
    \item Every method in the program may safely be used in other programs.
\end{enumerate}
\end{enumerate}
