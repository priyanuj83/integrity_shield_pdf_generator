\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following spreadsheet functions would be most useful for detecting improbably high or low values that have become part of a data set as a result of data entry errors?
\begin{enumerate}[label=(\alph*)]
    \item A function that averages numeric values in a column or row
    \item A function that counts the values in a column or row
    \item A function that rounds a numeric value
    \item A function that sorts values in a column or row
\end{enumerate}
\item Let l = [1,2,3,4]. What is max(l) in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item 1
    \item 2
    \item 3
    \item 4
\end{enumerate}
\item What is the output of 4*1**4 in python?
\begin{enumerate}[label=(\alph*)]
    \item 4
    \item 1
    \item 256
    \item 16
\end{enumerate}
\item In Python 3, what is the output of print list[1:3] if list = [ 'abcd', 786 , 2.23, 'john', 70.2 ]?
\begin{enumerate}[label=(\alph*)]
    \item [ 'abcd', 786 , 2.23, 'john', 70.2 ]
    \item abcd
    \item [786, 2.23]
    \item None of the above.
\end{enumerate}
\item The boolean expression a[i] == max || !(max != a[i]) can be simplified to
\begin{enumerate}[label=(\alph*)]
    \item a[i] == max
    \item a[i] != max
    \item a[i] \textless{} max || a[i] \textgreater{} max
    \item FALSE
\end{enumerate}
\end{enumerate}
