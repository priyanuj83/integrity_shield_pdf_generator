\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item A subset H of a group (G,*) is a group if
\begin{enumerate}[label=(\alph*)]
    \item a,b in H=\textgreater{} a * b in H
    \item a in H =\textgreater{} a^-1 in H
    \item a,b in H=\textgreater{} a * b^-1 in H
    \item H contains the identity element
\end{enumerate}
\item In the xy-plane, the curve with parametric equations x = cos t and y = sin t, 0 \textless{}= t \textless{}= pi, has length
\begin{enumerate}[label=(\alph*)]
    \item 3
    \item pi
    \item 3 pi
    \item 3/2
\end{enumerate}
\item If the finite group G contains a subgroup of order seven but no element (other than the identity) is its own inverse, then the order of G could be
\begin{enumerate}[label=(\alph*)]
    \item 27
    \item 28
    \item 35
    \item 37
\end{enumerate}
\item Statement 1 | R is a splitting field of some polynomial over Q. Statement 2 | There is a field with 60 elements.
\begin{enumerate}[label=(\alph*)]
    \item True, True
    \item False, False
    \item True, False
    \item False, True
\end{enumerate}
\item Find the sum of the given polynomials in the given polynomial ring. f(x) = 4 x - 5, g(x) = 2 $x^2$ - 4 x + 2 in Z\_8[x].
\begin{enumerate}[label=(\alph*)]
    \item 2 $x^2$ + 5
    \item 6 $x^2$ + 4 x + 6
    \item 0
    \item $x^2$ + 1
\end{enumerate}
\end{enumerate}
