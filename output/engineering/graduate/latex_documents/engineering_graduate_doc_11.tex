\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Find the variance of the random variable, Z = X + Y if X and Y are not independent.
\begin{enumerate}[label=(\alph*)]
    \item VarZ = VarX + VarY - 2 E[\{X - E(X)\}\{Y - E(Y)\}]
    \item VarZ = |VarX - VarY|
    \item VarZ =VarX +VarY
    \item VarZ = VarX + VarY + Cov(X,Y)
    \item VarZ = (VarX + VarY) / 2
\end{enumerate}
\item While operating on variable frequency supplies, the AC motor requires variable voltage in order to
\begin{enumerate}[label=(\alph*)]
    \item extend the motor's lifespan.
    \item increase the motor's efficiency.
    \item reduce the motor's noise.
    \item maintain a constant speed.
    \item improve the motor's torque.
\end{enumerate}
\item An SCR has half cycle surge current rating of 3000 A for 50 Hz supply. One cycle surge current will be

    \item 7000 A.
    \item 5000 A.
\end{enumerate}

    \item 1/6

\end{enumerate}
