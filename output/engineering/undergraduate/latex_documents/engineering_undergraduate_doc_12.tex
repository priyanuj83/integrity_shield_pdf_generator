    \item Joule

\item Use the derivative property of Laplace transforms to solve the differential equation y' - y = e^-x(1) where y(0) = 0 is the initial value of y.
\begin{enumerate}[label=(\alph*)]
    \item sinh x
    \item $e^x$ - e^-x

\item Potentiometer method of DC voltage measurement is more accurate than direct measurement using a voltmeter because
\begin{enumerate}[label=(\alph*)]
    \item It does not load the circuit at all.
    \item It uses a potentiometer, which is more accurate than a voltmeter.
    \item It uses a more precise measuring tool than a voltmeter.
    \item It uses centre zero galvanometer instead of voltmeter.
    \item It uses an ammeter instead of a voltmeter.

\item Express the Boyle temperature of a van der Waals gas in terms of the constants a, b, and R. The final expression for T\_B must contain only a, b, and R.
\begin{enumerate}[label=(\alph*)]
    \item T\_B = (a / 2 bR)
    \item T\_B = (R / ab)
    \item T\_B = (2 a / bR)
    \item T\_B = ($aR^2$ / b)
    \item T\_B = (bR / a)
\end{enumerate}
\end{enumerate}
