\section*{Multiple Choice (20 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following memories uses one transistor and one capacitor as basic memory unit
\begin{enumerate}[label=(\alph*)]
    \item SRAM
    \item DRAM
    \item Both SRAM and DRAM
    \item None
\end{enumerate}
\item In a lap winding dc machine number of conductors are 100 and number of parallel paths are 10. Find the average pitch
\begin{enumerate}[label=(\alph*)]
    \item 10
    \item 100
    \item 50
    \item 1
\end{enumerate}
\item While operating on variable frequency supplies, the AC motor requires variable voltage in order to
\begin{enumerate}[label=(\alph*)]
    \item protect the insulation.
    \item avoid effect of saturation.
    \item improve the capabilities of the inverter.
    \item protect thyristor from dV / dt.
\end{enumerate}
\item One of the following is the primary function of an oscillator
\begin{enumerate}[label=(\alph*)]
    \item produces sinusoidal oscillations
    \item generates non sinusoidal waveforms
    \item generates sustained oscillations at a constant amplitude and specific frequency
    \item none of the above
\end{enumerate}
\item \_\_\_\_\_\_\_\_ is the most detrimental impurity in the magnetic materials
\begin{enumerate}[label=(\alph*)]
    \item Carbon.
    \item Sulphur.
    \item Oxygen.
    \item Nitrogen.
\end{enumerate}
\item The resistivity of the conductor depends on
\begin{enumerate}[label=(\alph*)]
    \item area of the conductor.
    \item length of the conductor.
    \item type of material.
    \item none of these.
\end{enumerate}
\item If all the elements in a particular network are linear, then the superposition theorem would hold, when the excitation is
\begin{enumerate}[label=(\alph*)]
    \item DC only
    \item AC only
    \item Either AC or DC
    \item An Impulse
\end{enumerate}
\item According to the Bohr model, an electron gains or losses energy only by
\begin{enumerate}[label=(\alph*)]
    \item moving faster or slower in an allowed orbit.

    \item jumping from one atom to another atom.

\item Electrons in p-type material of a semi-conductor are called as
\begin{enumerate}[label=(\alph*)]
    \item either minority carriers or majority carriers
    \item minority carriers
    \item majority carriers
    \item valance carriers
\end{enumerate}
\item Which oscillators are easy to fabricate in a monolithic IC?
\begin{enumerate}[label=(\alph*)]
