\section*{Multiple Choice (20 marks)}
\begin{enumerate}[label=\arabic*.]
\item Elements with partially filled 4f or 5f orbitals include all of the following EXCEPT
\begin{enumerate}[label=(\alph*)]
    \item Cu
    \item Gd
    \item Eu
    \item Am
\end{enumerate}
\item Helium effuses through a pinhole 5.33 times faster than an unknown gas. That gas is most likely
\begin{enumerate}[label=(\alph*)]
    \item CO2
    \item CH4
    \item C5H12
    \item C8H18
\end{enumerate}
\item The number of allowed energy levels for the 55Mn nuclide are:
\begin{enumerate}[label=(\alph*)]
    \item 3
    \item 5
    \item 8
    \item 4
\end{enumerate}
\item The Pauli exclusion principle states that
\begin{enumerate}[label=(\alph*)]
    \item no two electrons can have the same four quantum numbers
    \item no two electrons with the same spin can occupy an orbital
    \item no two electrons can occupy separate orbitals
    \item no two electrons can pair up if there is an empty orbital available
\end{enumerate}
\item Of the following solutions, which will have the highest ionic strength? (Assume complete dissociation.)
\begin{enumerate}[label=(\alph*)]
    \item 0.050 M AlCl3
    \item 0.100 M NaCl
    \item 0.050 M CaCl2
    \item 0.100 M HCl
\end{enumerate}
\item Which of the following lists the electromagnetic spectral regions in order of decreasing wavelength?
\begin{enumerate}[label=(\alph*)]
    \item ultraviolet, visible, infrared, X-ray
    \item X-ray, visible, ultraviolet, infrared
    \item X-ray, ultraviolet, visible, infrared
    \item infrared, visible, ultraviolet, X-ray
\end{enumerate}
\item Which of the following is lower for argon than for neon?
\begin{enumerate}[label=(\alph*)]
    \item Melting point
    \item Boiling point
    \item Polarizability
    \item First ionization energy
\end{enumerate}
\item The photoelectron spectrum of carbon has three equally sized peaks. What peak is at the lowest energy?
\begin{enumerate}[label=(\alph*)]
    \item The 1s peak has the lowest energy.
    \item The 2s peak has the lowest energy.
    \item The 2p peak has the lowest energy.
    \item The 1p peak has the lowest energy.
\end{enumerate}
\item Calculate the Larmor frequency for a proton in a magnetic field of 1 T.
\begin{enumerate}[label=(\alph*)]
    \item 23.56 GHz
    \item 42.58 MHz
    \item 74.34 kHz
    \item 13.93 MHz
\end{enumerate}
\item The solid-state structures of the principal allotropes of elemental boron are made up of which of the following structural units?
\begin{enumerate}[label=(\alph*)]
    \item B12 icosahedra
    \item B8 cubes
    \item B6 octahedra
    \item B4 tetrahedra
\end{enumerate}
\end{enumerate}

\item True or False: The correct answer to 'To prepare a buffer, all of the following are needed except' is 'triple-distilled water'.

\end{enumerate}
