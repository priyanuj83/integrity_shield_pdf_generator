\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item 23 Na has an NMR frequency of 198.52 MHz in a 750 MHz NMR spectrometer. What is its magnetogyric ratio?
\begin{enumerate}[label=(\alph*)]
    \item 101.1 x $10^7$ T-1 s-1
    \item 26.75 x $10^7$ T-1 s-1
    \item 7.081 x $10^7$ T-1 s-1
    \item 0.9377 x $10^7$ T-1 s-1
\end{enumerate}
\item The +1 oxidation state is more stable than the +3 oxidation state for which group 13 element?
\begin{enumerate}[label=(\alph*)]
    \item B
    \item Al
    \item In
    \item Tl
\end{enumerate}
\item Cobalt-60 is used in the radiation therapy of cancer and can be produced by bombardment of cobalt-59 with which of the following?
\begin{enumerate}[label=(\alph*)]
    \item Neutrons
    \item Alpha particles
    \item Beta particles
    \item X-rays
\end{enumerate}
\item Which of the following is always true of a spontaneous process?
\begin{enumerate}[label=(\alph*)]
    \item The process is exothermic.
    \item The process does not involve any work.
    \item The entropy of the system increases.
    \item The total entropy of the system plus surroundings increases.
\end{enumerate}
\item Calculate the polarization of a proton in a magnetic field of 335 mT and 10.5 T at 298 K.
\begin{enumerate}[label=(\alph*)]
    \item 6.345 x 10^-4 at 0.335 T; 9.871 x 10^-5 at 10.5 T
    \item 0.793 x 10^-4 at 0.335 T; 6.931 x 10^-7 at 10.5 T
    \item 1.148 x 10^-6 at 0.335 T; 3.598 x 10^-5 at 10.5 T
    \item 4.126 x 10^-3 at 0.335 T; 2.142 x 10^-6 at 10.5 T
\end{enumerate}
\end{enumerate}
