\section*{Multiple Choice (10 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following is true for Br$_{2}$ at standard temperature and pressure?
\begin{enumerate}[label=(\alph*)]
    \item It is a colorless gas.
    \item It is a red-brown volatile liquid.
    \item It is a colorless volatile liquid.
    \item It is a yellow metallic solid.
\end{enumerate}
\item A buffer is made from equal concentrations of a weak acid and its conjugate base. Doubling the volume of the buffer solution by adding water has what effect on its pH?
\begin{enumerate}[label=(\alph*)]
    \item It has little effect.
    \item It significantly increases the pH.
    \item It significantly decreases the pH.
    \item It changes the pH asymptotically to the pKa of the acid.
\end{enumerate}
\item 23 Na has an NMR frequency of 198.52 MHz in a 750 MHz NMR spectrometer. What is its magnetogyric ratio?
\begin{enumerate}[label=(\alph*)]
    \item 101.1 x $10^7$ T-1 s-1
    \item 26.75 x $10^7$ T-1 s-1
    \item 7.081 x $10^7$ T-1 s-1
    \item 0.9377 x $10^7$ T-1 s-1
\end{enumerate}
\item A substance that is NOT generally considered to be a toxic pollutant in water is
\begin{enumerate}[label=(\alph*)]
    \item carbonic acid
    \item a halogenated hydrocarbon
    \item lead
    \item mercury
\end{enumerate}
\item Which of the following is a primary standard for use in standardizing bases?
\begin{enumerate}[label=(\alph*)]
    \item Ammonium hydroxide
    \item Sulfuric acid
    \item Acetic acid
    \item Potassium hydrogen phthalate
\end{enumerate}
\end{enumerate}
