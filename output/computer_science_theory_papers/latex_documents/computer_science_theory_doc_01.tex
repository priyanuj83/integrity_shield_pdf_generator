\section*{Multiple Choice (20 marks)}
\begin{enumerate}[label=\arabic*.]
\item Which of the following is correct about Python?
\begin{enumerate}[label=(\alph*)]
    \item It supports automatic garbage collection.
    \item It can be easily integrated with C, C++, COM, ActiveX, CORBA, and Java.
    \item Both of the above.
    \item None of the above.
\end{enumerate}
\item Church's thesis equates the concept of "computable function" with those functions computable by, for example, Turing machines. Which of the following is true...
\begin{enumerate}[label=(\alph*)]
    \item It was first proven by Alan Turing.
    \item It has not yet been proven, but finding a proof is a subject of active research.
    \item It can never be proven.
    \item It is now in doubt because of the advent of parallel computers.
\end{enumerate}
\item A large Java program was tested extensively, and no errors were found. What can be concluded?
\begin{enumerate}[label=(\alph*)]
    \item All of the preconditions in the program are correct.
    \item All of the postconditions in the program are correct.
    \item The program may have bugs.
    \item Every method in the program may safely be used in other programs.
\end{enumerate}
\item Which of the following characteristics of a programming language is best specified using a context-free grammar?
\begin{enumerate}[label=(\alph*)]
    \item Identifier length
    \item Maximum level of nesting
    \item Operator precedence
    \item Type compatibility
\end{enumerate}
\item Which of the following is NOT a property of bitmap graphics?
\begin{enumerate}[label=(\alph*)]
    \item Fast hardware exists to move blocks of pixels efficiently.
    \item Realistic lighting and shading can be done.
    \item All line segments can be displayed as straight.
    \item Polygons can be filled with solid colors and textures.
\end{enumerate}
\item In Python 3, what is the output of ['Hi!'] * 4?
\begin{enumerate}[label=(\alph*)]
    \item ['Hi!', 'Hi!', 'Hi!', 'Hi!']
    \item ['Hi!'] * 4
    \item Error
    \item None of the above.
\end{enumerate}
\item Which of the following has the greatest potential for compromising a user's personal privacy?
\begin{enumerate}[label=(\alph*)]
    \item A group of cookies stored by the user's Web browser
    \item The Internet Protocol (IP) address of the user's computer
    \item The user's e-mail address
    \item The user's public key used for encryption
\end{enumerate}
\item Which of the following pairs of 8-bit, two's-complement numbers will result in overflow when the members of the pairs are added?
\begin{enumerate}[label=(\alph*)]
    \item 11111111, 00000001
    \item 00000001, 10000000
    \item 11111111, 10000001
    \item 10000001, 10101010
\end{enumerate}
\item In python 3, which of the following is floor division?
\begin{enumerate}[label=(\alph*)]
    \item /
    \item //
    \item \%
    \item |
\end{enumerate}
\item Let x = 8. What is x>>1 in Python 3?
\begin{enumerate}[label=(\alph*)]
    \item 3
    \item 4
    \item 2
    \item 8
\end{enumerate}
\end{enumerate}

\section*{True / False (20 marks)}
\textit{Answer True or False and justify briefly.}
\begin{enumerate}[label=\arabic*.]
\item True or False: The correct answer to 'Of the following problems concerning a given undirected graph G, which is currently known to be solvable in polynomial time?' is 'Finding a shortest cycle in G'.
\item True or False: The correct answer to 'Local caching of files is common in distributed file systems, but it has the disadvantage that' is 'A much higher amount of network traffic results'.
\item True or False: The correct answer to 'Which of the following is true of interrupts?' is 'They are generated when memory cycles are "stolen".'.
\item True or False: The correct answer to 'Which is the smallest asymptotically?' is 'O(n)'.
\item True or False: The correct answer to 'Any set of Boolean operators that is sufficient to represent all Boolean expressions is said to be complete. Which of the following is...' is '\{AND, OR\}'.
\item True or False: The correct answer to 'In Python 3, what is the output of print tuple[0] if tuple = ( 'abcd', 786 , 2.23, 'john', 70.2 )?' is 'abcd'.
\item True or False: The correct answer to 'Of the following sorting algorithms, which has a running time that is LEAST dependent on the initial ordering of the input?' is 'Merge sort'.
\item True or False: The correct answer to 'Which of the following best describes the primary way in which a distributed denial-ofservice (D D o S) attack differs from a denial-...' is 'The number of computers launching the attack'.
\item True or False: The correct answer to 'Which of the following best explains what happens when a new device is connected to the Internet?' is 'An Internet Protocol (IP) address is assigned to the device.'.
\item True or False: The correct answer to 'Of the following, which gives the best upper bound for the value of f(N) where f is a solution to the recurrence f(2N + 1) = f(2N) = f(N)...' is 'O(log N) + 0(1)'.
\end{enumerate}
